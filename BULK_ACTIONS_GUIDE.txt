Replace the following placeholders throughout:
  {table}       -> database table name         (e.g. latest_news)
  {module}      -> route/URL prefix            (e.g. news)
  {Module}      -> singular display name       (e.g. News)

STEP 1 — DATABASE MIGRATION (Add status column)
================================================================

Run in terminal:
  php artisan make:migration add_status_to_{table}_table --table={table}

Open the generated file in database/migrations/ and edit:

    public function up(): void
    {
        Schema::table('{table}', function (Blueprint $table) {
            $table->boolean('status')->default(1)->after('description');
        });
    }

    public function down(): void
    {
        Schema::table('{table}', function (Blueprint $table) {
            $table->dropColumn('status');
        });
    }

Then run:
  php artisan migrate

NOTE: If the table has no 'description' column, change ->after('description')
      to another existing column (e.g. ->after('title') or ->after('image')).

STEP 3 — CONTROLLER METHODS
================================================================

Add these 3 methods to the controller class
(app/Http/Controllers/Admin/{Controller}.php):

    // ── Toggle Status (single item) ─────────────────────────────
    public function toggleStatus($id)
    {
        $item = DB::table('{table}')->where('id', $id)->first();
        if ($item) {
            $newStatus = $item->status ? 0 : 1;
            DB::table('{table}')->where('id', $id)->update(['status' => $newStatus]);
        }
        return redirect()->back()->with('success', 'Status updated successfully.');
    }

    // ── Bulk Delete ──────────────────────────────────────────────
    public function bulkDelete(Request $request)
    {
        $ids = $request->input('ids');
        if ($ids) {
            foreach ($ids as $id) {
                $item = DB::table('{table}')->where('id', $id)->first();
                if ($item && !empty($item->image)) {
                    $path = public_path('images/{folder}/' . $item->image);
                    if (file_exists($path)) @unlink($path);
                }
                DB::table('{table}')->where('id', $id)->delete();
            }
            return response()->json(['success' => 'Deleted successfully.']);
        }
        return response()->json(['error' => 'No items selected.'], 400);
    }

    // ── Bulk Status Update ───────────────────────────────────────
    public function bulkStatus(Request $request)
    {
        $ids    = $request->input('ids');
        $status = $request->input('status');
        if ($ids) {
            DB::table('{table}')->whereIn('id', $ids)->update(['status' => $status]);
            return response()->json(['success' => 'Status updated successfully.']);
        }
        return response()->json(['error' => 'No items selected.'], 400);
    }

NOTE: If this module stores no image, remove the image unlink block
      from bulkDelete().

STEP 7 — INDEX VIEW: JAVASCRIPT (before @endsection)
================================================================

Paste this block just before @endsection at the bottom of the file:

    <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
    <script>
    $(document).ready(function () {

        // ── Select All ──────────────────────────────────────────
        $('#select-all').on('change', function () {
            $('.select-item').prop('checked', $(this).prop('checked'));
            toggleBulkActions();
        });

        // ── Individual Select ───────────────────────────────────
        $('.select-item').on('change', function () {
            var total   = $('.select-item').length;
            var checked = $('.select-item:checked').length;
            $('#select-all').prop('checked', total === checked);
            toggleBulkActions();
        });

        // ── Show / Hide bulk action toolbar ────────────────────
        function toggleBulkActions() {
            if ($('.select-item:checked').length > 0) {
                $('#bulk-actions').removeClass('d-none').addClass('d-flex');
            } else {
                $('#bulk-actions').removeClass('d-flex').addClass('d-none');
            }
        }

        // ── Bulk Delete (uses Bootstrap modal) ─────────────────
        $('#bulk-delete').on('click', function () {
            var ids = [];
            $('.select-item:checked').each(function () { ids.push($(this).val()); });
            if (ids.length === 0) return;

            var deleteModal = new bootstrap.Modal(document.getElementById('deleteConfirmModal'));
            $('#deleteConfirmModalLabel').text('Delete Selected {Modules}');
            $('#deleteConfirmMessage').text(
                'Are you sure you want to delete ' + ids.length + ' selected item(s)? This action cannot be undone.'
            );
            $('#confirmDeleteBtn').off('click.bulk').attr('href', '#');
            $('#confirmDeleteBtn').on('click.bulk', function (e) {
                e.preventDefault();
                deleteModal.hide();
                $.ajax({
                    url: "{{ route('{module}.bulk_delete') }}",
                    method: 'POST',
                    data: { ids: ids, _token: "{{ csrf_token() }}" },
                    success: function () { location.reload(); },
                    error:   function () { alert('Something went wrong!'); }
                });
            });
            deleteModal.show();
        });

        // ── Bulk Activate ───────────────────────────────────────
        $('#bulk-activate').on('click',   function () { updateStatus(1); });

        // ── Bulk Deactivate ─────────────────────────────────────
        $('#bulk-deactivate').on('click', function () { updateStatus(0); });

        function updateStatus(status) {
            var ids = [];
            $('.select-item:checked').each(function () { ids.push($(this).val()); });
            $.ajax({
                url: "{{ route('{module}.bulk_status') }}",
                method: 'POST',
                data: { ids: ids, status: status, _token: "{{ csrf_token() }}" },
                success: function () { location.reload(); },
                error:   function () { alert('Something went wrong!'); }
            });
        }

    });
    </script>

STEP 8 — FRONTEND: Show only Active items
================================================================

In routes/web.php (or the relevant frontend Controller), find
the query that fetches this module's data and add a status filter:

    BEFORE:
        $items = DB::table('{table}')->orderBy('order', 'asc')->get();

    AFTER:
        $items = DB::table('{table}')->where('status', 1)->orderBy('order', 'asc')->get();

If there is no 'order' column, just use:
        $items = DB::table('{table}')->where('status', 1)->get();
